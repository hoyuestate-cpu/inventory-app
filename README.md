# inventory-app

柴木材店 総務用 工事リスト

総務で使っていた工事リストのエクセル（毎月の「R8.9.21～」シート・工事種別一覧・最終工事番号一覧・JDL取込用CSV）を Web アプリにしたものです。営業管理アプリ（sales-management-app）・財務管理アプリ（finance-app）とは、プログラムもデータベースもパスワードも分けています。Next.js（App Router）+ Prisma + PostgreSQL で構築しています。

## 主な機能

- **工事の登録** — 年度と種別（1 新築／2 住宅以外／3 増改築／4 小工事／5 クレーム／6 アパート・自社／7 アパート・モデルハウス／9 販売）を選ぶと、工事番号が自動で振られる（その種別の最後の番号＋1。例: 264145）。番号の重複は登録時にはじく。日付はカレンダーから選び、和暦（R8.9.18）も横に表示する。工事名・契約先名は JDL の文字数（全角12文字・10文字）を数えて表示する
- **工事リスト** — 毎月21日〜翌月20日の分を1ページに表示（エクセルの月のシートと同じ単位）。前の月・次の月へ移動でき、件数と請負額の合計を出す
- **JDL取込用CSVのダウンロード** — エクセルの「【工事リスト】CSVデータ（サンプル)」と同じ形式（＜工事情報一覧＞〜＜工事情報一覧終了＞、日付は R080918、請負額はコンマなし）で、Shift_JIS のCSVを作る。前回出力した日時と、出力後に変更・追加した件数も表示する
- **工事種別一覧** — 年度ごとの「最終工事番号一覧」（種別ごとの最後の番号と次の番号）と、種別ごとの番号の台帳。番号・工事名・契約先で全年度を検索できる
- **エクセル取込** — これまでのエクセルをそのまま取り込める（最初に1回）。読めない日付などがあれば行ごとに知らせる。同じファイルを何回取り込んでも二重登録にならない
- **パスワード保護** — アプリ全体に共通パスワードを設定できる（`SITE_PASSWORD` 環境変数）

## デプロイ手順（Vercel）

1. [neon.tech](https://neon.tech) で**このアプリ専用の新しいプロジェクト**を作り、接続文字列（`postgresql://...`）をコピーする。営業・財務アプリのデータベースとは別にする
2. Vercel で「Add New」→「Project」から `inventory-app` を選んで Import する
3. 「Environment Variables」に次を追加する
   - `DATABASE_URL`：1 の接続文字列
   - `SITE_PASSWORD`：総務用の共通パスワード（未設定だとURLを知っている人は誰でも使えてしまうので設定を推奨）
4. 「Deploy」を押す。データベースの表はデプロイ時に自動で作られる
5. 発行された `〇〇.vercel.app` を開いてログインし、「エクセル取込」から今の工事リストのエクセル（.xlsx）を取り込む

## 毎月の使い方

1. 工事が決まったら「工事の登録」で種別を選び、工事名・日付・請負額（税抜）を入れて登録する（工事番号は自動）
2. 締め（20日）が過ぎたら「工事リスト」でその月を開き、「JDL取込用CSVをダウンロード」を押してJDLに取り込む
3. 竣工日などをあとから入れたときは、工事番号をクリックして修正する。修正した工事を前の月のCSVに入れ直したいときは「JDLへ送る月」を変える

## ローカルでの開発

```bash
npm install          # 依存関係のインストール（prisma generate も自動実行されます）
# .env.example を .env にコピーし、各値を設定する
npm run db:migrate   # データベースのマイグレーション
npm run dev          # 開発サーバーの起動（http://localhost:3000）
```

## 技術スタック

- Next.js 16（App Router） / TypeScript / Tailwind CSS
- Prisma + PostgreSQL
- read-excel-file（エクセルの読み取り）／ iconv-lite（Shift_JIS のCSV出力）
